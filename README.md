# Makieta systemu rezerwacji — Fundacja Niepodzielni

**https://mixturemarketing.github.io/rezerwacje-makieta/**

Klikalna makieta systemu rezerwacji wizyt: konsultacje 1:1, grupy wsparcia i warsztaty.
Trzy role — pacjent, psycholog, koordynator — przełączane paskiem na górze ekranu.

**To nie jest działający system.** Nie ma backendu, bazy ani prawdziwych płatności.
Stan siedzi w przeglądarce. Wszystkie rezerwacje, kwoty i pacjenci są zmyśleni.

Specjaliści, ceny i katalog usług odwzorowano z publicznych profili na
[niepodzielni.com](https://niepodzielni.com/psycholog/) (stan 4.08.2026).

## Co obejrzeć

| Ekran | Co pokazuje |
|---|---|
| `#/moje-wizyty` | Polityka odwołań w działaniu — wizyta w oknie 24 h i poza nim |
| `#/panel/dostepnosc` | Rytm tygodniowy plus wyklikiwanie pojedynczych godzin |
| `#/panel/rozliczenia` | Wynagrodzenie specjalisty bez rozbicia na prowizję |
| `#/koordynacja/wydarzenia` | Grupy i warsztaty: limity miejsc, lista rezerwowa |
| `#/koordynacja/reguly` | Macierz „co system robi sam” — cała polityka w ośmiu wierszach |

Strona ma `noindex`, więc nie trafi do wyszukiwarek — ale każdy, kto zna adres, ją otworzy.

To repo zawiera wyłącznie zbudowany plik. Kod źródłowy jest osobno.
